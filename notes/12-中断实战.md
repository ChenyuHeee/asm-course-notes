# 第12讲：中断实战

> 本周核心：学会自定义软件中断，掌握硬件时钟中断的链式/非链式写法，了解 TSR 驻留程序。

---

## 一、中断向量表速查

中断向量表位于 `0000:0000` 起 1024 字节，每个中断占 4 字节（偏移2字节 + 段地址2字节）：

| 中断号 | 向量地址 | 用途 |
|:-------|:--------|:-----|
| int 8h | `0:8*4` = `0:20h` | 时钟中断（每秒约 18.2 次） |
| int 9h | `0:9*4` = `0:24h` | 键盘中断 |
| int 80h | `0:80h*4` = `0:200h` | 用户自定义软件中断 |

**保存和修改中断向量的标准流程**：

```asm
; 保存旧向量
mov ax, es:[bx]       ; 偏移地址
mov dx, es:[bx+2]     ; 段地址
mov cs:old_xx[0], ax
mov cs:old_xx[2], dx
; 设置新向量（中间需要 cli/sti 保护）
cli
mov word ptr es:[bx], offset new_handler
mov word ptr es:[bx+2], seg new_handler
sti
```

## 二、自定义软件中断 int 80h

软件中断由 `int n` 指令触发，处理函数用 `iret` 返回。

### 完整示例：int 80h 实现 ax 左移一位

```asm
code segment
assume cs:code
old_80h dw 0, 0
int_80h:
   shl ax, 1          ; ax = ax * 2
   iret               ; ★ 中断返回（pop ip + pop cs + popf）

main:
   xor ax, ax
   mov es, ax         ; es = 0（中断向量表在 0 段）
   mov bx, 80h*4
   ; 保存旧向量
   mov ax, es:[bx]
   mov dx, es:[bx+2]
   mov cs:old_80h[0], ax
   mov cs:old_80h[2], dx
   ; 设置新向量
   mov word ptr es:[bx], offset int_80h
   mov word ptr es:[bx+2], seg int_80h   ; 也可写成 cs
   ; 测试
   mov ax, 1234h
   int 80h            ; ax = 2468h
   mov ah, 4Ch
   mov al, 0
   int 21h
code ends
end main
```

> `iret` = ① pop ip ② pop cs ③ popf。比 `retf` 多恢复一个 FL 寄存器。`int` 会 pushf + push cs + push ip，`iret` 逆序弹出。

## 三、硬件时钟中断 int 8h

int 8h 由 8253 定时器芯片约每秒触发 18.2 次，是硬件中断（IRQ0）。

### 3.1 非链式写法（自己发 EOI）

硬件中断处理完必须向 **8259A 中断控制器** 发送 EOI（End of Interrupt）信号：

```asm
code segment
assume cs:code
ticks dw 0
old_8h dw 0, 0

int_8h:
   cmp [ticks], 0
   je skip
   dec [ticks]        ; 倒计时 -1
skip:
   push ax            ; ★ 硬件中断可能破坏任何寄存器！
   mov al, 20h        ; EOI 信号 = 20h
   out 20h, al        ; 发送到 8259A 主片（端口 20h）
   pop ax
   iret

delay_1s:
   mov [ticks], 18    ; 18 次 ≈ 1 秒
wait_a_while:
   cmp [ticks], 0
   jne wait_a_while
   ret

main:
   xor ax, ax
   mov es, ax
   mov bx, 8*4
   ; 保存旧向量
   mov ax, es:[bx]
   mov dx, es:[bx+2]
   mov cs:old_8h[0], ax
   mov cs:old_8h[2], dx
   ; 设置新向量（修改向量表时必须关中断）
   cli                ; IF=0，禁止硬件中断
   mov word ptr es:[bx], offset int_8h
   mov word ptr es:[bx+2], seg int_8h
   sti                ; IF=1，重新允许硬件中断
   ; 每秒输出一个字母
   mov cx, 10
   mov dl, 'A'
again:
   mov ah, 2
   int 21h
   call delay_1s
   inc dl
   dec cx
   jnz again
   ; 恢复旧向量
   mov ax, old_8h[0]
   mov dx, old_8h[2]
   cli
   mov es:[bx], ax
   mov es:[bx+2], dx
   sti
   mov ah, 4Ch
   int 21h
code ends
end main
```

> 关键点：
> - **cli/sti**：修改中断向量表期间必须关中断，否则可能改到一半被中断打断
> - **EOI**：`mov al, 20h; out 20h, al`，告诉 8259A 本次中断已处理完毕
> - **保护寄存器**：硬件中断随时可能发生，必须在处理函数中 push/pop 所有用到的寄存器

### 3.2 链式写法（中断接力）

不自己发 EOI，而是 `jmp dword ptr cs:[old_8h]` 把控制权交给原中断处理程序，由它完成 EOI 发送：

```asm
int_8h:
   cmp [ticks], 0
   je skip
   dec [ticks]
skip:
   jmp dword ptr cs:[old_8h]   ; ★ 跳转到原 int 8h 处理程序
                                ; 原程序会负责发 EOI + iret
```

> 链式写法的优势：保留了原始中断的完整功能（如系统时钟更新），更安全。非链式写法完全接管中断，如果忘记发 EOI 会导致系统挂起。

## 四、TSR：常驻内存程序

TSR（Terminate and Stay Resident）是 DOS 时代的「后台程序」概念：程序退出但不释放内存，中断处理函数继续生效。

### 4.1 TSR 的实现：int 21h 功能 31h

```asm
mov dx, offset main  ; dx = 代码起点到 main 的距离
add dx, 100h         ; + PSP 长度（100h 字节）
add dx, 0Fh          ; \
shr dx, 4            ; / 向上取整到 16 字节边界（以节为单位）
mov ah, 31h
int 21h              ; 驻留并退出
```

> `int 21h / ah=31h` 告诉 DOS：保留当前程序的 dx 节（paragraph = 16字节）内存，其余释放。`(offset main + 100h + 0Fh) / 10h` 算出需要保留的节数。

### 4.2 实战：修改 PC-Man 游戏生命值

利用 int 8h 时钟中断，通过 TSR 驻留在后台，每秒检查并修改 PC-Man 游戏的生命值：

```asm
.386
code segment use16
assume cs:code
old_8h dw 0, 0

int_8h:
   push ax
   push bx
   push ds
   mov ah, 62h
   int 21h            ; bx = 当前程序的 PSP 段地址
   mov ds, bx
   cmp byte ptr ds:[985h], 48h   ; 检查游戏是否在运行
   jne skip
game_is_running:
   mov byte ptr ds:[1809h], 0Bh  ; 生命值设为 11
skip:
   pop ds
   pop bx
   pop ax
   jmp dword ptr cs:[old_8h]     ; 链式调用原 int 8h

main:
   xor ax, ax
   mov es, ax
   mov bx, 8*4
   mov ax, es:[bx]
   mov dx, es:[bx+2]
   mov cs:old_8h[0], ax
   mov cs:old_8h[2], dx
   cli
   mov word ptr es:[bx], offset int_8h
   mov word ptr es:[bx+2], seg int_8h
   sti
   ; 计算驻留内存大小
   mov dx, offset main
   add dx, 100h
   add dx, 0Fh
   shr dx, 4
   mov ah, 31h
   int 21h            ; TSR 驻留，程序退出但中断处理函数仍在工作
code ends
end main
```

> 核心技巧：
> - `mov ah, 62h; int 21h` → bx = PSP 段地址，通过 PSP 可以访问游戏的整个内存空间
> - PSP 偏移 `985h` 处的值 = `48h` 表示游戏正在运行
> - PSP 偏移 `1809h` 处存储的是生命值，始终设为 `0Bh`（11）实现无限生命
> - 使用链式中断不破坏原 int 8h 功能

## 五、本周易错点

1. 修改中断向量表时忘记 `cli`/`sti`，可能导致系统崩溃
2. 硬件中断处理函数中忘记 push/pop 寄存器，导致被中断的程序状态被破坏
3. 硬件中断忘记发 EOI（非链式），系统会停止响应后续硬件中断
4. TSR 程序驻留内存大小计算错误，可能导致内存泄漏或程序被截断
5. `iret` vs `retf` 搞混：`iret` 多弹一个 FL，用在中断；`retf` 用在远调用

| 取中断向量 | `mov ax, es:[n*4]` + `mov dx, es:[n*4+2]` |
| 设中断向量 | `mov es:[n*4], ax` + `mov es:[n*4+2], dx` |
| 关中断 | `cli` |
| 开中断 | `sti` |
| 发 EOI | `mov al, 20h; out 20h, al` |
| 读键盘扫描码 | `in al, 60h` |
| 获取 PSP | `mov ah, 62h; int 21h` → bx |
| 驻留退出 | `mov ah, 31h; int 21h` |
| 中断返回 | `iret` |
| 中断接力 | `jmp dword ptr cs:[old_xx]` |
